# Report 217: SSRM-3D playable community crisis governance, resource triage, rumor, restorative appeals, and trust memory bridge

## Status

Pass. The deterministic bridge generated a community-scale crisis governance substrate with scarce resource ledgers, triage decisions, rumor dynamics, restorative appeals, long-term trust memory, frequency/flower timing, and browser replay.

This is not real crisis management, real medicine, public-health authority, real consent, subjective suffering, consciousness, or moral patienthood.

## Purpose

Report 216 made public-health governance playable under outbreak-like uncertainty. Report 217 widens the world pressure: a small society now has to allocate scarce blankets, cups, repair tools, water, and medicine while rumors create stigma risk and unresolved social debt.

The target is not a clean optimization toy. The target is a first-person artificial-life community where scarcity can hurt trust, rumors can damage dignity, appeals can repair part of the harm, and long-term memories carry consequences forward.

## Crisis object loop

The bridge adds explicit community-crisis objects.

| Object | Function |
| --- | --- |
| `ResourceStock` | Tracks resource kind, location, available units, baseline need, scarcity pressure, wear or spoilage risk, access constraint, vibration rate, and flower node. |
| `CrisisPolicy` | Tracks scarcity trigger, scope, rule, rollback condition, care exception, public reason, minority note, review interval, frequency, and flower node. |
| `TriageDecision` | Tracks requested and allocated units, priority basis, need score, fairness score, care continuity, autonomy boundary, visible body marker, unresolved debt, and trust delta. |
| `RumorRecord` | Tracks rumor claim, source, target, channel, evidence status, harm risk, spread rate, correction action, residual belief, stigma guardrail, trust delta, frequency, and flower node. |
| `RestorativeAppeal` | Tracks harm claim, requested repair, circle members, decision, resolution, repair action, dignity preservation, future rule change, and trust delta. |
| `TrustMemory` | Tracks durable multi-year relationship memory, trust before/after, social debt, relationship tag, sealed private digest, and future visible behavior. |
| `EventRecord` | Binds resource, rumor, trust, public fact, private digest, readable marker, vibration rate, and flower phase into one trace. |
| `ReplayFrame` | Converts crisis events into browser-readable first-person replay frames. |

The integrated loop is:

```text
browser tick
-> resource stock pressure
-> crisis policy proposal
-> triage decision
-> unresolved social debt
-> rumor formation or correction
-> restorative appeal circle
-> rule adjustment or deferral
-> long-term trust memory
-> visible behavior marker
-> replay frame
```

## Scenario coverage

The generated scenario includes:

- `5` agents: Ari, Fay, Milo, Nia, and Sol.
- `5` scarce resource ledgers: blankets, dry cups, repair tools, clean water, and medicine kit.
- `3` crisis policies.
- `8` triage decisions.
- `5` rumors, with `4` corrected and `1` unresolved.
- `5` restorative appeals, with `4` resolved and `1` deferred.
- `5` long-term trust memories.
- `31` replayable crisis events.

The scenario makes crisis governance socially consequential. Milo's blanket and tool delays become appealable social debt. Sol's water allocation becomes a rumor that needs embodied repair through shared carrying duty. Fay's medicine stockout is separated from a character accusation without exposing care history. Nia's deferred privacy boundary stays sealed but leaves rumor residue. Ari's repair lane is protected, but public receipts are needed to avoid status capture.

## Honest interpretation

The bridge passes, but it is not solved governance.

Resource triage fairness is `0.682851`, because scarcity produces defensible but still uneven allocations. Care continuity is `0.750000`, because not every triage decision protects continuity. Appealable debt traceability is only `0.500000`, because some unresolved debt is carried forward without immediate appeal. Rumor correction is `0.800000`, because Nia's archive privacy rumor remains unresolved. Restorative appeal resolution is `0.800000`, because one boundary appeal is deferred. Trust repair is `0.725968`, because social debt remains after the crisis.

That is the point. A convincing little society should remember hard choices instead of wiping them clean at the end of the run.

## Boundary

This report proves deterministic wiring for community-crisis governance inside an artificial-life benchmark. It does not prove real crisis management, medicine, public-health validity, real consent, subjective feeling, suffering, consciousness, or moral patienthood.

The frequency and flower-of-life overlays are inspectable rhythm and phase scaffolds for the simulation. They are not metaphysical evidence.
