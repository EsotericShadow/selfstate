## Embodied ecology object loop

The bridge adds material-life objects.

| Object | Function |
| --- | --- |
| `LifeStageRecord` | Tracks birth year, observed age, life stage, household, lineage role, energy, fatigue, hunger, cold exposure, wetness, pain, apprenticeship track, sealed workspace digest, frequency, and flower node. |
| `IllnessCareRecord` | Tracks illness trigger, public symptoms, body-rate signal, care action, recovery time, relapse risk, stigma guardrail, sealed private body digest, and trust delta. |
| `ApprenticeshipRecord` | Tracks learner, mentor, craft, body practice, tool/material, completion, injury or fatigue risk, consent boundary, visible behavior, and inherited phrase. |
| `HabitatProject` | Tracks structure, materials, labor, weather pressure, comfort gain, safety gain, maintenance debt, community rule, frequency, and flower node. |
| `AgricultureCycle` | Tracks crop or food material, season, water/labor needs, yield, spoilage, storage, ritual/institution link, and sensory marker. |
| `WeatherSeason` | Tracks temperature, rainfall, wind, soundscape, smellscape, body cost, crop effect, shelter effect, frequency, and flower node. |
| `MaterialExchange` | Tracks household exchange, material, quantity, purpose, scarcity pressure, reciprocity memory, fairness, debt, and ledger visibility. |
| `AvatarEntryProtocol` | Blocks avatar entry until embodied history, life records, material cycles, and weather cycles exist, while preserving pre-entry noninterference and private body boundaries. |
| `EventRecord` | Binds body, ecology, economy, public fact, sealed private digest, readable marker, vibration rate, and flower phase into one replayable trace. |
| `ReplayFrame` | Converts embodied ecology events into browser-readable replay frames where the avatar remains outside until the ecology briefing finishes. |

The integrated loop is:

```text
weather season
-> body cost and life-stage update
-> illness or care event
-> apprenticeship body practice
-> habitat construction or maintenance debt
-> agriculture cycle and storage risk
-> material exchange and reciprocity memory
-> late avatar-entry gate check
-> replay frame
```

## Honest interpretation

The bridge passes, but embodied ecology is deliberately fragile.

Food storage security is `0.617125`, material fairness after debt is `0.734812`, illness recovery is `0.750000`, agriculture yield stability is `0.750000`, and apprenticeship completion is `0.833333`. This report makes the world more physically believable. It does not yet create local 3D spatial bodies, navigable rooms, weather volumes, crop plots, object pickup, or live avatar conversation.
