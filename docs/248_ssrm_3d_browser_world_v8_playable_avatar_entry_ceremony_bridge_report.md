## Honest implementation note

The first local run failed with readiness `0.974095` but weakest channel `0.777778`. The weak channel was `welfare_rollback_safety`, because it required every welfare check to pass before rollback counted. That duplicated `welfare_boundary_respect` instead of measuring rollback/recovery availability. The final code separates those channels: welfare quality remains imperfect at `0.962963`, while rollback/recovery availability is measured independently at `1.000000`.

The new weakest channel is `typed_local_act_handling` at `0.889722`. That is the correct pressure point. Typed input is still deterministic parser routing, not open-ended language understanding.
