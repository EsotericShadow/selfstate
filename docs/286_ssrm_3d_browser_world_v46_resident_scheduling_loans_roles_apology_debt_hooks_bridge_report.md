# Report 286: SSRM-3D Browser World v46 Resident Scheduling/Loans/Roles/Apology Debt-Hooks Bridge

## Purpose

Report 286 extends the browser-world line with autonomous resident-to-resident scheduling, negotiated object loans over multiple days, visible household roles, animated apology/forgiveness arcs, and avatar conversation hooks for remembered inventory debts.

This is deterministic browser-local scaffolding. It does not claim subjective consciousness, real consent, moral patienthood, autonomous natural language, or a complete 3D engine. The advance is that resident scheduling and object loans now happen between residents, with household roles, forgiveness limits, and debt-aware avatar hooks layered on top.

## Boundary

Deterministic browser-local resident-scheduling/object-loan/household-role/apology-debt-hook scaffold only; no LLM call, subjective consciousness, real consent, autonomous natural language, moral patienthood, complete gameplay, complete 3D engine, or metaphysical frequency claim.

## Method

The generator runs 192 session days with 18 ticks per day across six settlements. Each settlement carries four residents, household roles, rooms, owned objects, resident routine tasks, sound/smell cues, frequency metadata, object custody, trust, debt, resentment, reload counters, schedule counters, loan counters, forgiveness counters, and debt-hook counters.

Each tick records a resident-to-resident schedule, four household role rows, a browser tick, and conditional negotiated loan rows, apology/forgiveness arcs, avatar debt conversation hooks, and reload probes. The browser artifact exposes controls for resident schedules, loan negotiation, household role boards, forgiveness arcs, debt hooks, return help, debt-memory reload, save/restore, and replay export.
