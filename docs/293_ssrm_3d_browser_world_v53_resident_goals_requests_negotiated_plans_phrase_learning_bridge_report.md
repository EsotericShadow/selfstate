# Report 293: SSRM-3D Browser World v53 Resident Goals Requests Negotiated Plans Phrase Learning Bridge

## Purpose

Report 293 extends the browser-world line from bounded phrasebook dialogue into resident agency during dialogue. The benchmark adds resident-owned goals, object/task requests, multi-turn negotiated plans, refusal-aware help offers, and bounded phrase learning that persists across reloads without LLM calls.

This is deterministic browser-local scaffolding. It does not claim subjective consciousness, real consent, moral patienthood, autonomous natural language, or a complete 3D engine. The advance is that residents are no longer only conversational partners. They bring goals, ask for help with objects and tasks, counter the avatar's plan, refuse help, and teach bounded phrases that persist.

## Boundary

Deterministic browser-local resident-goal/request/negotiated-plan/refusal-aware-help/phrase-learning scaffold only; no LLM call, subjective consciousness, real consent, autonomous natural language, moral patienthood, complete gameplay, complete 3D engine, or metaphysical frequency claim.

## Method

The experiment builds from the v52 phrasebook dialogue bridge and adds a deterministic v53 resident-goal loop over 162 plan days and 2916 browser ticks. Each tick samples a settlement, resident, resident-owned goal, object/task request, permission state, multi-turn plan state, avatar help offer, resident boundary, bounded phrase correction, inherited history hash, frequency, and flower phase.

The new loop records seven evidence families: resident-owned goal frames, object/task request frames, multi-turn negotiated plan frames, refusal-aware help offer frames, bounded phrase learning frames, goal-dialogue reload probes, and browser ticks. Frequency and flower-of-life fields remain deterministic timing/rate metadata for goal pressure and phrase learning cadence, not metaphysical claims.

Resident agency is intentionally measured. A pass cannot come from treating residents as puppets who simply accept avatar actions. Goals must remain resident-owned, object permissions must be checked, plans must support counters/revisions/refusals, help must be useful without coercion, and phrase learning must persist without claiming autonomous language or using LLMs.

## Honest interpretation

Report 293 does not create real autonomy, real language learning, subjective experience, real consent, moral patienthood, or open-ended planning. It creates deterministic browser-local evidence that residents can own goals and negotiate around them instead of merely reacting to avatar prompts.

The important gain is resident initiative. Dialogue now leads to object/task requests, multi-turn plan negotiation, refusal-aware help, and phrase learning from residents. That makes the simulation more person-like in function because residents have projects and boundaries that persist beyond a single turn.

The capped weakest channel is deliberate. The right direction is not avatar-centered command execution. The resident should be able to say what they are trying to do, ask for specific help, counter a bad plan, refuse a help offer, and teach a bounded phrase without becoming an LLM-driven chatbot.
